# @gvray/mathkit

Mathematical utilities: arithmetic precision, statistics, geometry, random number generation, and number checks.

## Installation

```sh
npm i @gvray/mathkit
# or
yarn add @gvray/mathkit
# or
pnpm add @gvray/mathkit
```

## Documentation

Full API reference: **[gvray.github.io/toolkit/api/mathkit/](https://gvray.github.io/toolkit/api/mathkit/)**
