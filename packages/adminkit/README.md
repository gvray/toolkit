# @gvray/adminkit

Admin-focused utilities: clipboard, localStorage, event bus, loading state, menu, table, tree, and data export.

## Installation

```sh
npm i @gvray/adminkit
# or
yarn add @gvray/adminkit
# or
pnpm add @gvray/adminkit
```

## Documentation
