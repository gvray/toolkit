# @gvray/colorkit

Color manipulation utilities: parsing, hex/RGB conversion, HSL, lightening, darkening, and color mixing.

## Installation

```sh
npm i @gvray/colorkit
# or
yarn add @gvray/colorkit
# or
pnpm add @gvray/colorkit
```

## Documentation

Full API reference: **[gvray.github.io/toolkit/api/colorkit/](https://gvray.github.io/toolkit/api/colorkit/)**
