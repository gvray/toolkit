# @gvray/eskit

Core JavaScript/TypeScript utilities: collections, deep clone, debounce, curry, compose, tree operations, and type checks.

## Installation

```sh
npm i @gvray/eskit
# or
yarn add @gvray/eskit
# or
pnpm add @gvray/eskit
```
