# @gvray/datekit

Date and time utilities: formatting, duration, timezone, comparison, and validation.

## Installation

```sh
npm i @gvray/datekit
# or
yarn add @gvray/datekit
# or
pnpm add @gvray/datekit
```

Full API reference: **[gvray.github.io/toolkit/api/datekit/](https://gvray.github.io/toolkit/api/datekit/)**
