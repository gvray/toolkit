# @gvray/formatkit

Data formatting utilities: numbers, text, time, file size, and mask patterns.

## Installation

```sh
npm i @gvray/formatkit
# or
yarn add @gvray/formatkit
# or
pnpm add @gvray/formatkit
```

## Documentation

Full API reference: **[gvray.github.io/toolkit/api/formatkit/](https://gvray.github.io/toolkit/api/formatkit/)**
