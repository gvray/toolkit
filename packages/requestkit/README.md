# @gvray/requestkit

Async request utilities: retry, polling, timeout, memoize, rate limiting, deferred, and abort groups.

## Installation

```sh
npm i @gvray/requestkit
# or
yarn add @gvray/requestkit
# or
pnpm add @gvray/requestkit
```

## Documentation

Full API reference: **[gvray.github.io/toolkit/api/requestkit/](https://gvray.github.io/toolkit/api/requestkit/)**
