# @gvray/validationkit

Data and form validation utilities: type validators, schema validation, async validation, and form helpers.

## Installation

```sh
npm i @gvray/validationkit
# or
yarn add @gvray/validationkit
# or
pnpm add @gvray/validationkit
```
