# @gvray/pathkit

Path manipulation utilities: URL parsing, query string handling, path normalization, and joining.

## Installation

```sh
npm i @gvray/pathkit
# or
yarn add @gvray/pathkit
# or
pnpm add @gvray/pathkit
```

## Documentation

Full API reference: **[gvray.github.io/toolkit/api/pathkit/](https://gvray.github.io/toolkit/api/pathkit/)**
